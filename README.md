# websites

## showtime-theme

WordPress block theme for **Showtime Entertainment** — a full-service event
management and infrastructure company (est. 2010, Klerksdorp & Sandton,
South Africa). Built from the design handoff: five pages (Home, Services,
Portfolio, About, Contact + quote form), full-screen menu overlay,
pure-black austere-luxury design language.

Install: copy `showtime-theme/` into `wp-content/themes/` and activate
(WordPress 6.5+). See `showtime-theme/readme.txt` for setup details —
activation seeds the pages and the six portfolio entries automatically.
